Routis est un site indépendant : il n'est affilié à aucun organisme officiel suisse (OFROU, services cantonaux des automobiles, TCS, bpa) et n'est pas approuvé par eux. Ce contenu est un outil de révision rédigé par Routis à partir de sources publiques ; ce ne sont pas les questions de l'examen officiel.
