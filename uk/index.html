How does it work?

Four simple steps to prepare for the car theory test.

  1. 1

    Learn

    Read the short courses and learn the road signs, with the Highway Code rule numbers.

  2. 2

    Practise

    Practise by topic, in the 60-second express challenge, or with the hazard perception scenes.

  3. 3

    Take a mock test

    50 questions in 57 minutes, like the real test. You need 43 to pass, and you see every correction.

  4. 4

    Review your mistakes

    At the end of each test you see what you got wrong and the rule behind each answer.

Frequently asked questions

Is it really free?

Yes. Everything on Routis UK is free, with no sign-up.

Is this the official theory test?

No. Routis is an independent site. The questions are original and based on the Highway Code. The real test is run by the DVSA.

Does Routis use real exam questions?

No. The official question bank is not public. Our questions follow the same topics as the real test, and each answer shows the Highway Code rule.

Is the content up to date?

It was checked against the Highway Code on GOV.UK in October 2026. Rules change, so always check the official text if you are unsure.
