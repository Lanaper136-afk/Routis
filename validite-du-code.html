Validité du code de la route : 5 ans, échecs, repasser le code

Combien de temps le code est-il valable ? Que se passe-t-il si on échoue à l'examen pratique ? Et si les 5 ans sont écoulés ? Voici les réponses, simplement.

1. Combien de temps le code est-il valable ?

  • Le code de la route (l'ETG, épreuve théorique générale) est valable 5 ans à partir du jour où tu le réussis.
  • Ce délai ne peut pas être prolongé.
  • La date de fin de validité est indiquée dans le courrier ou l'e-mail qui t'annonce ton résultat.
  • Pendant ces 5 ans, tu dois passer et réussir l'examen pratique.

2. Et si je rate l'examen pratique ?

  • Tant que ton code est valide, tu peux te représenter à l'examen pratique sans repasser le code.
  • Il existait autrefois une limite de 5 passages. Elle a été supprimée fin 2022 : aujourd'hui, seule la durée de 5 ans compte.
  • Il faut juste réserver une nouvelle place d'examen.

3. Si le code est expiré

  • Si les 5 ans sont écoulés sans avoir réussi l'examen pratique, il faut repasser le code.
  • Tu t'inscris en candidat libre, auprès du centre d'examen de ton choix, comme la première fois.
  • L'inscription à l'ETG est facturée 30 €.
  • Une fois le code réussi, tu réserves une nouvelle place pour l'examen pratique.

4. Réussir le code

  • L'examen comporte 40 questions. Il faut 35 bonnes réponses pour réussir, soit 5 fautes au maximum.
  • Les questions portent sur les panneaux, la réglementation, les usagers, les situations de conduite, la sécurité et les premiers secours.
  • Entraîne-toi avec des examens blancs dans les mêmes conditions : 40 questions, 20 secondes par question.

5. Bien organiser son permis

  • Passe le code quand tu es prêt, mais pas trop longtemps avant tes leçons de conduite : les 5 ans commencent dès que tu réussis.
  • Prévois assez d'heures de conduite avant l'examen pratique pour rester dans les 5 ans.
  • Garde la date de fin de validité sous les yeux dans ton agenda.
