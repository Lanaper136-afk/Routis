L'examen du code de la route : comment ça se passe

L'épreuve théorique générale (ETG), c'est le « code ». Elle est passée sur écran, dans un centre d'examen agréé.

1. Le déroulement

L'examen comporte 40 questions avec images ou courtes vidéos. Il faut obtenir au moins 35 bonnes réponses : on peut donc faire au maximum 5 erreurs. Chaque question a une ou plusieurs bonnes réponses ; il faut toutes les cocher et aucune de fausse.

Les résultats sont connus rapidement, et le code est valable 5 ans, avec 5 tentatives à l'épreuve pratique dans cette période.

2. Les thèmes

Les questions portent sur la circulation, le conducteur, la route, les autres usagers, la réglementation, la sécurité des passagers, les équipements du véhicule, les notions de mécanique et de premiers secours, et l'environnement. C'est exactement l'organisation des fiches de Routis.

3. Comment réviser

  • Faites un examen blanc régulièrement et notez les thèmes où vous échouez.
  • Relisez les fiches correspondantes, puis refaites un quiz.
  • Apprenez les panneaux par famille (danger, interdiction, obligation, indication).
  • Révisez en petites séances (15 à 20 minutes) plutôt qu'une longue séance la veille.
